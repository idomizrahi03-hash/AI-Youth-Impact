

# AI Youth Impact: Human Skills & Risk Indicators Framework

## Project Overview
**AI Youth Impact** is an analytical research and data project designed to investigate the intersection between adolescent Artificial Intelligence (AI) usage patterns, human cognitive skills, and potential usage risks.

The core objective is to analyze whether and how generative AI tool adoption among high school students correlates with human skill development (e.g., Critical Thinking, Metacognition, Problem Solving) or potential dependency indicators (e.g., Cognitive Offloading, Decision Outsourcing).

---

## Core Modules
1. **Module 1: AI × Human Skills Framework**
   Analyses relationships between AI usage types/intensity and core cognitive/social capabilities.
2. **Module 2: AI Risk Radar (Experimental)**
   Identifies potential behavioral indicators of reliance or unbalanced AI usage.

> **Important Note:** This project is a data analysis and research framework. It is **not** a diagnostic, psychological, or medical tool.
